# EBRAINS-eeg-meditation-vs-stress

# EEG Analysis of Meditation and Stress States

This project investigates differences in EEG activity between meditative and stress states using signal processing, statistical analysis, and computational methods.

## Team Members
Nauman Khalid Qureshi, Yildiz Dilara Parry, Ana Carolina Filipe, Pablo Torijam, Simone Vagnoni, Giulia Debonis, Pier Paolucci, Gianluca Gaglioti

## Dataset

The project uses the publicly available ⁠OpenNeuro ds003969 (v1.0.0).

## Objectives

* Preprocess EEG recordings and perform quality control.
* Explore EEG characteristics across meditative and stress conditions.
* Apply complementary analytical methods to identify differences in neural activity.
* Compare and interpret findings across methods.

## Workflow

1. Preprocessing: Filtering, artefact removal, and segmentation.
2. Analysis: EEG feature extraction and statistical comparisons.
3. Validation: Evaluation and interpretation of results.
4. Reporting: Visualisation and documentation of findings.

## Status

Work in progress — October 2026 onwards.
